구글 시트 연결
URL과 암호는 이 기기 브라우저에만 저장돼요. 파일 안에는 들어가지 않아요.
공용 PC나 남의 폰에서 썼다면 꼭 눌러 주세요. URL·암호·불러온 기록이 이 기기에서 지워져요.
처음 연결하는 순서
  1. 이 용도 전용 구글 계정에서 새 시트 "AI비서 협업" 만들기
  2. 확장 프로그램 → Apps Script에 Code.gs 붙여넣기
  3. setup 실행 → 로그의 TOKEN(32자리) 메모 · 사본으로 받았어도 꼭 직접 실행
  4. 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자)
  5. URL·TOKEN을 위 칸에 넣고 저장
  6. 피클에 같은 구글 계정을 연결
